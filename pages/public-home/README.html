Omega Platform — Public Documentation

The world-readable entry point for OmegaAI agents. Every tree below is public and navigable by path with qo ls/qo read.

Contents

  • OQL Language — the Omega Query Language reference.
  • Components — how to install and use ready-made OmegaAI components (AI Connector, Omega Agent, Cron Runner).
  • LinkedIn Connector — install and use the LinkedIn connector.
  • OAuth — sign in to GitHub (and other OAuth providers) once and get a current token, for example for git in a devcontainer; the servers are listed at Public/OAuth Servers.
  • Composio — connect Gmail, Slack and other apps through Composio, then search for and run their tools from any workspace; the servers are listed at Public/Composio Servers.
